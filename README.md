# React Calculator (TypeScript)

シンプルな四則演算に対応した React + TypeScript 製の電卓アプリです。Vite を使用した軽量な構成で、数字入力、四則演算、小数点、クリア、バックスペース、イコールをサポートします。

## セットアップ

1. 依存パッケージをインストールします。
   ```bash
   npm install
   ```
2. 開発サーバーを起動します。
   ```bash
   npm run dev
   ```
3. ビルドする場合は次のコマンドを使用します。
   ```bash
   npm run build
   ```

※ 環境によってはネットワークポリシーによりパッケージ取得が制限されることがあります。その場合はローカルの npm ミラーなどをご利用ください。

## 主な機能

- 四則演算（+、-、×、÷）
- 小数点入力
- 現在の入力をリセットするクリアボタン
- 1 文字削除するバックスペース
- 直前の計算内容を表示しつつ計算結果を整形表示

## プロジェクト構成

- `src/App.tsx`: 電卓のロジックと UI
- `src/App.css`: スタイル
- `src/main.tsx`: React アプリのエントリーポイント
- `vite.config.ts`: Vite 設定
